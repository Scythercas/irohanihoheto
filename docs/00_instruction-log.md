# 指示履歴ログ（AI Instruction Log）

本ファイルは、ユーザーからAI（Claude）への指示を **一字一句変更せず** 原文のまま保管する記録です。
併せて、各指示に対するClaude側の対応内容を要約して残し、会話の流れを追えるようにします。

## 運用ルール

- ユーザー発言は原文ママ。誤字・空白・改行も含め一切修正しない（コードフェンス内に格納）。
- Claudeの応答は「要約」として記載する（全文は不要）。
- 新しい指示があるたびに、このファイルの末尾に追記する。
- 決定事項は要約に留め、正式な仕様は `docs/` 配下の設計書側を正とする。
- 中断（Interrupted）された発言は、確定指示として扱わず注記のみ残す。
