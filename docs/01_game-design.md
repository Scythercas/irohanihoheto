## 1. コンセプト

### 1.0 タイトル 【確定：K1】

## 『いろはにほへと』

由来と意味（**シナリオ・演出・宣材のすべてで拠り所にすること**）:

- **いろは** ＝ 主人公「色葉」の名前
- **いろはにほへと** ＝ 「恋愛のいろは」＝ 初歩・基本。マチアプ初心者の物語という内容に合致
- **いろは歌の本歌**「**色は匂へど 散りぬるを／我が世たれぞ 常ならむ**」
  → **「色は美しく香っても、散ってしまう。この世に変わらないものなどあるだろうか」**
  → **5人の色（葵・翠・橙香・紫音・桃果）と出会い、そのすべてが散っていく**という本作の構造そのもの
  → B4②「フェードアウト」＝**自然消滅**という別れの描き方が、タイトルによって必然になる
  → そして**散らずに残るのが茉白だけ**である、という結末の意味づけになる

> **設計上の含意**: タイトル決定により、「5人との別れ＝フェードアウト」は妥協ではなく**作品の主題**になった。
> 懸念R1（5人が踏み台に見える）は、テーマ側からも回収されたと判断する。
> エピローグ（H4②）では、散った5つの色それぞれが**その後どう咲いているか**に触れることで、
> 「散る」を否定的にせず、無常観として着地させる。

### 1.1 一行コンセプト 【確定】

> 「色のない男が、五つの色に触れて、白に辿り着く話。」

**【2026-08-15 変更】幼馴染の名を「茜」→「茉白（ましろ）」に、髪色を茜色→白に変更した。**
名前＝髪色の規則により、**総合パラメータの色も赤から白になった**。
以前は「全色平均＝赤」に必然性がなかったが、**白は五色の光がすべて重なった色**なので、
「5色すべてが閾値以上のときだけ茉白ルートに入る」というルールと比喩が一致する。
また、いろは歌「色は匂へど散りぬるを」に対し、
**茉白が散らないのは、彼女が「色」ではないから**という説明が立つようになった。

### 1.2 中核メタファーとメカニクス 【確定：A1・C1】

- 登場人物は名前に対応した髪色を持つ
- 主人公 **色葉** は"まだ染まっていない葉"＝**無彩色**。物語を通して色を得ていく
- 主人公は**5つのパラメータ**を持ち、それぞれ色分けされている
- **アプリで出会う5人が求めるパラメータの色と、5人の髪色が対応している**
  - → どれか**1つの色を磨けば、その人と交際できる**
  - → **すべてを平均的に引き上げれば、茉白と付き合える**
- マッチングアプリ **「カラット」** は宝石の単位。ヒロインは色石として提示される
- UI・ルート識別・演出色すべてにキャラ色を一貫使用する

## 3. ゲームシステム

### 3.1 5色パラメータ制 【確定：C1】

- 魅力は単一値ではなく**5色パラメータ**（誠実さ／包容力／ユーモア／感性／自信）で管理
- **個別ルート突入条件**: 対応する1色が閾値以上
- **茉白ルート（トゥルー）突入条件**: 5色すべてが一定以上
- → 「1人に入れ込むと茉白に届かない」トレードオフがルールとして成立
- ビジュアル表現: 主人公の無彩色シルエットが色づいていく

### 3.2 進行構造 【確定：C2・A4】

- **週スケジュール制**。作中期間 約3ヶ月＝**約12週**
- 1週につき数回の行動枠を消費し、「誰と会うか／誰に連絡するか」を選択
- 終盤に分岐判定

### 3.3 UI・演出 【確定：C5・C6・H3】

| 要素 | 方針 |
|---|---|
| メッセージ画面 | **LINE風チャットUIで返信を選択。作り込む**（ゲームの中心）。**ゲーム画面の中にスマホを1台置き、その画面の中で会話する**【2026-08-15 追加】 |
| プロフィール閲覧・スワイプ・マッチング演出 | **簡易表現**（静止画＋短い演出） |
| パラメータ表示 | 数値は出さず、**ぼかした表現**（表情・短評）のみ |
| ヒント | **茉白に相談すると明確なヒントが得られる** |
| ナビゲーター音声 | **なし**（K4②）。マッチング等は効果音とテキストで処理する |

### 3.4 セーブ・補助機能 【確定：H2】

| 機能 | 有無 |
|---|---|
| 手動セーブ／ロード | **あり** |
| オートセーブ（章の切れ目） | **あり** |
| クリア後のシーン回想・エンディング一覧 | **あり** |
| **バッドエンド直前への巻き戻し** | **なし**（C4③「救済なし」の実体） |

### 3.5 エンディング構成 【確定】

| 種別 | 条件 | 数 |
|---|---|---|
| 茉白ルート（トゥルー） | 5色すべてが閾値以上 ＋ 誰とも交際確定していない | 1 |
| 個別ルート | 対応色が閾値以上 | 5 |
| サッドエンド | 総合魅力レベル未達 → **茉白に見限られる** | 1 |

**判定規則 【確定：K11③】＝「個別ルート優先」**

上から順に評価し、最初に成立したものを採る。

1. 対応する色が `THRESHOLD.INDIVIDUAL` 以上のヒロインがいれば → **その個別ルート**
   （複数該当したら値が最大の色。同値なら好感度、それも同値ならパラメータの定義順）
2. 誰も該当せず、5色すべてが `THRESHOLD.MASHIRO_ALL` 以上 → **茉白ルート**
3. どちらでもない → **サッドエンド**

> **§3.5 の「誰とも交際確定していない」の実体**は、1 に該当しないこと＝**どの色にも特化しなかったこと**である。
> つまり茉白ルートは `[MASHIRO_ALL, INDIVIDUAL)` という**帯**になる。
> 「すべてを平均的に引き上げれば茉白と付き合える」（§1.2）が、ルール上そのまま成立する。

**帯であることの副作用と対策**

プレイヤーには数値を見せない（C3②）ため、**帯の上に外れたことに気づけない**。
そこで次の2つで担保する。

- 帯を十分広く取る（現在 45〜79）。行動枠を使い切っても、均等に遊ぶかぎり上に突き抜けない点数設計にしてある
- **`npm run balance`** が、行動枠の配分を総当たりして7エンディングすべての到達性を毎回検証する

実装は `src/game/engine.ts` の `endingRoute()`。シナリオ側は `branch` の `ifEnding:` で結果を受け取るだけで、
しきい値も優先順位もシナリオには書かない（変えるときに一箇所で済むようにするため）。

**ヒロインとの別れの扱い 【確定：B4②＋H4①②】**

- 明確な失恋・お別れシーンは作らず、**フェードアウト**（＝マチアプでは自然消滅が普通というリアリティ）
- ただし緩和策として:
  - **①各ヒロインの最後のメッセージだけ残す**（既読スルーではなく、短い前向きな一言で終わる）
  - **②エピローグで5人の「その後」に一行ずつ触れる**

> 一方で **R2（ボリューム過多）が再燃**する。対策は「1人あたりのデート本数を増やす」
> のではなく、**書き下ろしのデート＋繰り返し用の「重ねの一日」**という二層構成で吸収する
> （`05_implementation-status.md` §6）。

技術選定は Phase2 で行い、`docs/03_tech-stack.md` に記載する。

## 5. アセット方針 【確定：F1〜F6・I】

**大方針: 制作費0円。** 正規の無料手段のみで賄う（詳細は `02_open-questions.md` §I改）。

| 種別 | 方針 |
|---|---|
| 立ち絵 | AI生成。**ローカル実行または無料枠のあるサービス**で0円化【Phase2で確定】 |
| ボイス | **主要シーンのみ部分ボイス**。**VOICEVOX等の無料AI音声**が基本。葵は知人収録を検討 |
| 音声処理 | ユーザーにノイズ除去の知識なし → **無料ツールでの定型手順をClaude側で用意する** |
| BGM | **フリー素材（DOVA-SYNDROME・甘茶の音楽工房等）＋AI生成** |
| 効果音 | フリー素材（効果音ラボ等）【暫定】 |
| 背景 | フリー素材／AI生成【暫定】 |
| 公開 | itch.io・WEBホスティングとも**無料枠で完結** |

> **注意 【重要】**: ユーザーから「複数アカウントを用いる」案が出たが、多くのAIサービスは
> **同一人物による複数アカウント作成を利用規約で禁止**しており、アカウント停止や生成物の利用権が
> 不安定になるリスクがある。**規約に沿った無料手段だけで0円制作は達成可能**なため、この方法は採らない。
