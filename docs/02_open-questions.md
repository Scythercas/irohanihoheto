## G. ヒロイン5人の人物像（B1=③「全面的に相談したい」を受けて）

A1で「**5つのパラメータと5人の色が対応し、その色を磨けばその人と付き合える**」が確定したため、
**人物像はパラメータから逆算して設計**します。まず色↔パラメータの対応を確定させ、その後に人物像を選びます。

### G1. 色とパラメータの対応（この割り当てでよいか）

| 色 | キャラ | パラメータ案 | 意味 |
|---|---|---|---|
| 青 | 葵 | **誠実さ** | 嘘をつかない、約束を守る、言動が一貫している |
| 翠 | 翠 | **包容力** | 聞く、受け止める、相手のペースを尊重する |
| 橙 | 橙香 | **ユーモア** | 場を明るくする、笑わせる、緊張をほぐす |
| 紫 | 紫音 | **感性** | 美しいものが分かる、作品や趣味について自分の言葉で語れる |
| 桃 | 桃果 | **自信** | 堂々としている、流されない、主導権を持てる |

→ **G1: ①この割り当てで確定 ②入れ替えたい（どれとどれ？） ③パラメータ名を変えたい**

## H. 要調整点の確認（回答どうしの整合）

### H1. 【重要】知人の声を当てる「脇役」が存在しない

- F4「知人は声。脇役がよい」 ↔ B5「サブキャラは不要（①）」
- このままだと**知人に振れる役が1つもありません**。以下から選んでください（複数可）。

| 案 | 内容 |
|---|---|
| ① | アプリ「カラット」のナビゲーター／システムボイス（「マッチングしました！」等）※短文中心で頼みやすい |
| ② | 店員・受付など、デート先のモブ数人 |
| ③ | 業者アカウントのキャラ（コメディ枠。E2①と相性◎） |
| ④ | B5を撤回し、男友達キャラを1人追加する |
| ⑤ | 知人依頼はやめてAI音声に一本化する |

→ 推奨: **①＋③**（短い定型セリフ中心なので、演技経験がなくても成立する）

### H2. C4③「救済なし」の適用範囲

「救済なし」は**バッドエンド直前に巻き戻す機能を付けない**、という理解で合っています。
そのうえで、以下は付けてよいでしょうか。

| # | 機能 | 質問 |
|---|---|---|
| a | 手動セーブ／ロード | ①付ける ②付けない（完全一発勝負） |
| b | オートセーブ（章の切れ目） | ①付ける ②付けない |
| c | クリア後のシーン回想・エンディング一覧 | ①付ける ②付けない |

→ 推奨: **a=① b=① c=①**。
理由: D1で1周2〜3時間のため、セーブ不可だと中断もできません。「救済なし」の緊張感は**巻き戻し不可**で十分に担保できます。

### H3. C5②「カラット画面は簡易」 ↔ C6①「LINE風チャットUI」

以下の切り分けでよいか確認です。

- **作り込む**: メッセージ画面（LINE風チャットUI、返信選択） ← ゲームの中心
- **簡易にする**: プロフィール閲覧・スワイプ・マッチング演出 ← 静止画＋短い演出で処理

→ **H3: ①この切り分けでOK ②違う（希望を記載）**

### H4. B4②「フェードアウト」でよいか（再確認）

ヒロインに明確な失恋・お別れシーンを作らない方針ですが、これは
**「マッチングアプリでは自然消滅が普通」というリアリティ**（A2②・E2①）と噛み合うため、私は妥当だと考えます。
ただし「5人が茜のための踏み台に見える」懸念は残ります。緩和策として:

| 案 | 内容 |
|---|---|
| ① | 各ヒロインの最後のメッセージだけ残す（既読スルーではなく、短い前向きな一言で終わる） |
| ② | エピローグで5人の「その後」を一行ずつ触れる |
| ③ | 緩和策は不要。完全にフェードアウトさせる |

→ 推奨: **①＋②**（工数はごく小さく、後味が大きく変わる）

### H5. 茜の「ツンデレ＋レベル到達でデレ発動」の設計

B2の回答を仕様に落とすと以下になります。これでよいか確認です。

- 総合魅力レベルに**しきい値を複数**設ける（例: Lv2 / Lv3 / Lv4 / Lv5）
- 到達するたびに**茜の専用イベントが解放**され、少しずつデレる
- 通常時は口が悪く、素直に褒めない（ツンデレ）
- **B3②の茜視点の幕間**で、本人が自覚していない揺れを描く
- 最終しきい値に到達していれば茜ルート、未達なら**B4の「見限られサッドエンド」**

→ **H5: ①この設計でOK ②修正したい**

### 【重要】複数アカウントについて

Iのご回答にあった「複数アカウントを用いる」方法は、**採用しないことをおすすめします。**

- 多くのAI生成サービスは、**同一人物による複数アカウント作成を利用規約で明確に禁止**しています
- 発覚するとアカウント停止に加え、**生成済みアセットの商用・公開利用の権利が不安定になります**
- 無料公開（D4①）とはいえ、規約違反の素材で作った作品は itch.io 等での公開時にリスクが残ります

そして何より、**その必要がありません。** 規約に沿った無料手段だけで0円制作は十分可能です。

| 種別 | 無料の手段 | 備考 |
|---|---|---|
| 立ち絵 | ローカルで画像生成AIを動かす（GPUがあれば枚数無制限・完全無料）／無料クレジットが毎日回復するサービスを数ヶ月使う | K3の回答で最適解が決まる |
| ボイス | **VOICEVOX**（無料・商用可・クレジット表記のみ） | 日本語キャラボイスとして実用十分 |
| BGM | DOVA-SYNDROME、甘茶の音楽工房 | 無料・商用可 |
| 効果音 | 効果音ラボ | 無料・商用可 |
| 背景 | フリー素材＋AI生成 | — |
| 公開 | itch.io、GitHub Pages 等 | **完全無料** |

→ 「数ヶ月かける」方針（I）は**そのまま有効**です。時間をかければ規約内で足ります。

### K1『いろはにほへと』についての所見

ユーザー独自案だが、**当初のClaude案（無彩色のイロハ）より優れている**と判断。理由:

1. 「色葉（いろは）」＋「恋愛のいろは（初歩）」の二重の意味は同じく成立している
2. さらに**いろは歌の本歌「色は匂へど 散りぬるを」＝「美しい色も散ってしまう」**という含意が加わる
3. これが **B4②「5人とはフェードアウトで終わる」** という設計に**必然性**を与える
   → 妥協ではなく**主題**になる。懸念R1（5人が踏み台に見える）がテーマ側から回収された
4. 日本語圏で誰もが知る語であり、覚えやすく検索もされやすい
