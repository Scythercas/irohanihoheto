#### 【重要】再配布禁止への対応

**素材ファイルは公開リポジトリに含めていない。**
`.gitignore` で `public/assets/bg/` を除外し、取得は各自 `npm run fetch:assets` で行う運用にしている。

- 理由: 本リポジトリは**パブリック**であり、素材をそのまま置くと
  「素材としての再配布」に当たると判断されうるため
- ビルド成果物（GitHub Pages / itch.io に置く `dist/`）には当然含まれるが、
  それは**作品への利用**であり規約上問題ない

#### ライセンスの調査結果（2026-08-15 確認）

**「商用利用禁止」という情報の出どころが2つあり、内容が食い違っていたため原典で確認した。**

**① Fair AI Public License 1.0-SD の本文**（<https://freedevproject.org/faipl-1.0-sd/>）

| 条項 | 内容 |
|---|---|
| Output | **"The output of this software is not covered by this license, and no contributor claims any rights to it."** → **生成画像はライセンスの対象外**。貢献者は権利を主張しない |
| 商用利用 | **禁止条項は存在しない** |
| Modify / 配布 | モデルの学習・マージも「改変」に含まれる。**派生モデルを配布するなら**、同ライセンス（または同等の許可）とソース（重み）の提供が必要 |
| Network | モデルをネットワーク越しに使わせる場合、ソースの入手手段を提供する必要がある |
| クレジット | 明示的な表記義務なし |

→ **ライセンス本文だけを見れば、生成画像の利用に制限はない。**

**② Civitai のモデルページ上で作者が設定した許諾**（API で取得した実データ）

| 設定 | 値 | 意味 |
|---|---|---|
| `allowCommercialUse` | **`[RentCivit, Rent]`** | 有料生成サービス上での実行は可。**`Image` が含まれていない ＝ 生成画像の販売は不可** |
| `allowNoCredit` | `true` | クレジット表記は不要 |
| `allowDerivatives` | `true` | 派生モデルの作成は可 |
| `allowDifferentLicense` | `true` | 派生を別ライセンスで公開してもよい |

→ **実効的な制限は「生成画像を販売してはいけない」。** これが「商用利用がいけない」という記述の実体。

#### 本作への影響 —— **現状の方針なら問題なし**

| 用途 | 可否 | 理由 |
|---|---|---|
| **完全無料で配布する**（D4①・現在の方針） | **✅ 問題なし** | 販売にあたらない |
| パブリックリポジトリに立ち絵PNGを置く | **✅ 問題なし** | ライセンス本文で出力は対象外。無償公開は販売ではない |
| itch.io / ノベルゲームコレクションでの無料公開 | **✅ 問題なし** | 同上 |
| クレジット表記 | 任意 | `allowNoCredit: true` |
| **itch.io の「投げ銭（Name your own price）」** | **❌ 避ける** | 生成画像を含む作品を対価付きで配布することになり、抵触の恐れ |
| **有料販売** | **❌ 不可** | 同上 |
| モデルファイル自体の再配布 | 不要（していない） | しないので条件は発生しない |

> **【確定】D4①「完全無料」の方針は維持する。** 将来「投げ銭あり」に切り替える選択肢は、
> このモデルを使い続ける限り**取れない**。収益化したくなった場合は、
> `allowCommercialUse` に `Image` を含むモデルで**立ち絵を作り直す**必要がある。

> **注意**: 本記載は公開情報（ライセンス本文とCivitaiのAPIが返す許諾設定）の要約であり、
> 法的助言ではない。また本モデルは**マージ**であるため、上流モデル
> （Illustrious-XL、NoobAI 等）の条件も重ねて確認するのが安全。
> なお Illustrious-XL 本体（<https://civitai.com/models/795765>）も
> `allowCommercialUse: [RentCivit, Rent]` で同じ扱いだった。

## 5. 将来、収益化したくなった場合の手順

### 結論: **ブロッカーは立ち絵だけ。** 他の素材はすべて商用利用可

| 素材 | 商用可否 | 対応 |
|---|---|---|
| **立ち絵（AI生成）** | **❌ 販売不可** | **作り直しが必要** |
| 背景（みんちりえ） | ✅ 商用OK | そのまま使える |
| 背景（ゲームまてりあるず） | ✅ 商用OK | そのまま使える |
| BGM（DOVA-SYNDROME／甘茶の音楽工房） | ✅ 商用OK | そのまま使える |
| 効果音（効果音ラボ） | ✅ 商用OK | そのまま使える |
| ボイス（VOICEVOX） | ✅ 商用OK | クレジット表記が必要 |
| コード・シナリオ | ✅ 自作 | 制限なし |

### 手順

**Step 1. 差し替え先のモデルを選ぶ**

条件は **`allowCommercialUse` に `Image` が含まれていること**。
Civitai API で機械的に確認できる。

```powershell
Invoke-RestMethod "https://civitai.com/api/v1/models/1188071" |
  Select-Object name, @{n='商用';e={$_.allowCommercialUse -join ','}}
```

2026-08-15 時点で条件を満たす主なアニメ系チェックポイント:

| モデル | id | allowCommercialUse | 備考 |
|---|---|---|---|
| **Animagine XL 4.0** | 1188071 | **`Image, RentCivit, Rent, Sell`** | **最も緩い。第一候補** |
| Animagine XL V3.1 | 260267 | `Image, RentCivit, Rent` | 実績豊富 |
| CAT - Citron Anime Treasure | 131986 | `Image, RentCivit, Rent` | Illustrious/Noob系 |
| Holy Mix [illustriousXL] | 959490 | `Image, RentCivit, Rent` | 現行モデルに絵柄が近い |
| Pony Diffusion V6 XL | 257749 | `Image, RentCivit` | 最大手だがタグ体系が独特 |

> **絵柄を今と近づけたいなら Illustrious系（CAT / Holy Mix）**、
> **確実さを取るなら Animagine XL 4.0**（`Sell` まで許諾されている）。

**Step 2. 立ち絵をすべて作り直す**

`docs/04_asset-guide.md` の手順をそのまま使う。**プロンプトは流用できる**が、
モデルが変わると seed の意味が変わるため、**`normal` の作り込みからやり直しになる**。

- 対象: **6人 × 7表情 = 42枚**（現時点では茜の7枚のみ）
- 手順: `normal` を作り込む → seed固定 → inpaint で表情6種 → `remove-bg.py` で一括透過

**Step 3. 差し替えと記録**

1. `public/assets/chara/<ID>/` の中身を入れ替える（**ファイル名は変えない**。コード変更不要）
2. 本ファイル §4 の表を新しいモデル名・ライセンス・seed で更新する
3. 旧モデルで作った画像を**リポジトリの履歴からも消したい場合**は、
   単純な削除コミットでは残るため、履歴の書き換えが必要になる点に注意

**Step 4. 公開設定を変える**

- itch.io のプロジェクト設定を「Name your own price」または有料に変更
- `docs/01_game-design.md` の D4、`docs/03_tech-stack.md` §9、`CLAUDE.md` §4.6 を更新

### 【最重要】判断は「量産前」に済ませること

**いま作り直すなら7枚。5人ぶん作ってからだと42枚。**
収益化の可能性が少しでもあるなら、**残り5人の立ち絵を作り始める前に決める**のが圧倒的に安い。

現在の方針（D4① 完全無料）を維持するなら、このまま進めてよい。

**Civitai等のモデルには商用利用や生成物の扱いに条件が付くものがある。**
使ったモデル名とライセンスを必ずここに記録すること。seed は表情差分を作り直すときに要る。
