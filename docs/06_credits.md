最終更新: 2026-08-15

> **【方針・2026-08-15 確定】立ち絵は、生成画像の商用利用が許諾されたモデルで作り直す。**
> 現在の茉白の立ち絵は**暫定**であり、公開前に差し替える。手順は §5。
> 差し替えが完了するまでは、**現行素材のままでの有料販売・投げ銭はできない**。

> **素材を使ったら、その場でここに記録すること。** 公開直前にまとめようとすると必ず破綻する。
> クレジット表記が必要な素材は、ゲーム内のクレジット画面にも反映する。

| キャラ | 生成環境 | モデル名 | seed |

- モデルページ: <https://civitai.com/models/835655>（作者: dims2）
- ベースライセンス: **Fair AI Public License 1.0-SD**

#### ライセンスの調査結果（2026-08-15 確認）

**「商用利用禁止」という情報の出どころが2つあり、内容が食い違っていたため原典で確認した。**

**① Fair AI Public License 1.0-SD の本文**（<https://freedevproject.org/faipl-1.0-sd/>）

| 条項 | 内容 |
|---|---|
| Output | **"The output of this software is not covered by this license, and no contributor claims any rights to it."** → **生成画像はライセンスの対象外**。貢献者は権利を主張しない |
| 商用利用 | **禁止条項は存在しない** |
| Modify / 配布 | モデルの学習・マージも「改変」に含まれる。**派生モデルを配布するなら**、同ライセンス（または同等の許可）とソース（重み）の提供が必要 |
| Network | モデルをネットワーク越しに使わせる場合、ソースの入手手段を提供する必要がある |
| クレジット | 明示的な表記義務なし |

→ **ライセンス本文だけを見れば、生成画像の利用に制限はない。**

**② Civitai のモデルページ上で作者が設定した許諾**（API で取得した実データ）

| 設定 | 値 | 意味 |
|---|---|---|
| `allowCommercialUse` | **`[RentCivit, Rent]`** | 有料生成サービス上での実行は可。**`Image` が含まれていない ＝ 生成画像の販売は不可** |
| `allowNoCredit` | `true` | クレジット表記は不要 |
| `allowDerivatives` | `true` | 派生モデルの作成は可 |
| `allowDifferentLicense` | `true` | 派生を別ライセンスで公開してもよい |

→ **実効的な制限は「生成画像を販売してはいけない」。** これが「商用利用がいけない」という記述の実体。

#### 本作への影響 —— **現状の方針なら問題なし**

| 用途 | 可否 | 理由 |
|---|---|---|
| **完全無料で配布する**（D4①・現在の方針） | **✅ 問題なし** | 販売にあたらない |
| パブリックリポジトリに立ち絵PNGを置く | **✅ 問題なし** | ライセンス本文で出力は対象外。無償公開は販売ではない |
| itch.io / ノベルゲームコレクションでの無料公開 | **✅ 問題なし** | 同上 |
| クレジット表記 | 任意 | `allowNoCredit: true` |
| **itch.io の「投げ銭（Name your own price）」** | **❌ 避ける** | 生成画像を含む作品を対価付きで配布することになり、抵触の恐れ |
| **有料販売** | **❌ 不可** | 同上 |
| モデルファイル自体の再配布 | 不要（していない） | しないので条件は発生しない |

> **【2026-08-15 更新】このモデルは使い続けない。**
> 上記の制限（生成画像の販売不可）を外すため、
> `allowCommercialUse` に `Image` を含むモデルへ移行することが決まった（§5）。
> ただし**移行が済むまでは、この表の制限がそのまま効く**。
> つまり現時点で公開するなら **完全無料に限る**。

> **注意**: 本記載は公開情報（ライセンス本文とCivitaiのAPIが返す許諾設定）の要約であり、
> 法的助言ではない。また本モデルは**マージ**であるため、上流モデル
> （Illustrious-XL、NoobAI 等）の条件も重ねて確認するのが安全。
> なお Illustrious-XL 本体（<https://civitai.com/models/795765>）も
> `allowCommercialUse: [RentCivit, Rent]` で同じ扱いだった。

## 5. 立ち絵を商用可モデルで作り直す手順 【確定：2026-08-15】

**ユーザー判断により、収益化の選択肢を残すため、立ち絵は商用利用が許諾されたモデルで作り直す。**
実施時期は **「残り5人の立ち絵に着手するとき」**（§4 の理由）。それまでは現行の茉白を暫定で使う。

### 結論: **ブロッカーは立ち絵だけ。** 他の素材はすべて商用利用可

| 素材 | 商用可否 | 対応 |
|---|---|---|
| **立ち絵（AI生成）** | **❌ 販売不可** | **作り直しが必要** |
| 背景（みんちりえ） | ✅ 商用OK | そのまま使える |
| 背景（ゲームまてりあるず） | ✅ 商用OK | そのまま使える |
| BGM（DOVA-SYNDROME／甘茶の音楽工房） | ✅ 商用OK | そのまま使える |
| 効果音（効果音ラボ） | ✅ 商用OK | そのまま使える |
| ボイス（VOICEVOX） | ✅ 商用OK | クレジット表記が必要 |
| コード・シナリオ | ✅ 自作 | 制限なし |

### 手順

**Step 1. 差し替え先のモデルを選ぶ**

条件は **`allowCommercialUse` に `Image` が含まれていること**。
Civitai API で機械的に確認できる。

```powershell
Invoke-RestMethod "https://civitai.com/api/v1/models/1188071" |
  Select-Object name, @{n='商用';e={$_.allowCommercialUse -join ','}}
```

**2026-08-15 に API で実データを確認した結果**（この表は再確認するまで信用してよい）:

| モデル | id | baseModel | allowCommercialUse | 判定 |
|---|---|---|---|---|
| **CAT - Citron Anime Treasure** | 131986 | **Illustrious / NoobAI** | `Image, RentCivit, Rent` | **★第一候補** |
| Holy Mix [illustriousXL] | 959490 | **Illustrious** | `Image, RentCivit, Rent` | 対抗 |
| Animagine XL 4.0 | 1188071 | SDXL 1.0 | **`Image, RentCivit, Rent, Sell`** | 許諾は最も広いが絵柄が変わる |
| Animagine XL V3.1 | 260267 | SDXL 1.0 | `Image, RentCivit, Rent` | 4.0の旧版。選ぶ理由が薄い |
| （現行）Illustrious XL personal merge | 835655 | Illustrious | `RentCivit, Rent` | **`Image` なし＝不可** |

**推奨は CAT - Citron Anime Treasure（IL v10）。** 理由は3つ。

1. **現行と同じ Illustrious 系**なので、**§2 のプロンプトと推奨パラメータがそのまま流用できる**
   （Animagine系はタグの効き方と既定の画風が違うため、プロンプトの作り直しになる）
2. `Image` が許諾されており、**生成画像を含む作品の販売が可能**
3. `allowDifferentLicense: false` だが、これは**派生モデルを配布する場合**の条件であり、
   本作はモデルを配布しないので**影響しない**

> Animagine XL 4.0 の `Sell` は「**モデル自体の販売**」まで許す設定であり、
> 本作に必要な `Image`（生成画像の商用利用）は3候補とも等しく満たしている。
> **`Sell` の有無で選ぶ必要はない。**

確認コマンド（作者が設定を変える可能性があるので、着手直前にもう一度流すこと）:

```powershell
Invoke-RestMethod "https://civitai.com/api/v1/models/131986" |
  Select-Object name, @{n='商用';e={$_.allowCommercialUse -join ','}}
```

**Step 2. 立ち絵をすべて作り直す**

`docs/04_asset-guide.md` §2〜§3 の手順をそのまま使う。

- 対象: **6人 × 7表情 = 42枚**
- 手順: `normal` を作り込む → **seedを固定** → inpaint で表情6種 → `remove-bg.py` で一括透過
- **プロンプトは流用できる**（Illustrious系を選んだ場合）。ただし **seed の意味はモデルごとに違う**ため、
  **`normal` の作り込みからやり直しになる**。記録済みの seed 2180441173 は新モデルでは無意味
- **茉白から作ること。** 既存の7枚と見比べれば、新モデルの絵柄が許容範囲かをすぐ判断できる。
  ここで気に入らなければ、まだ7枚しか無駄になっていない

**Step 3. 差し替えと記録**

1. 旧画像を `work-assets/chara/<ID>/_old_<モデル名>/` へ退避する
2. `public/assets/chara/<ID>/` の中身を入れ替える（**ファイル名は変えない**。コード変更は不要）
3. 本ファイル §4 の表を**新しいモデル名・ライセンス・seed** で更新する
4. 旧モデルの画像を**リポジトリの履歴からも消したい場合**は、単純な削除コミットでは残るため
   履歴の書き換えが要る。ただし**無料公開していた期間の配布自体は適法**なので、通常は不要

**Step 4. 収益化する場合のみ、公開設定を変える**

- itch.io のプロジェクト設定を「Name your own price」または有料に変更
- `docs/01_game-design.md` の D4、`docs/03_tech-stack.md`、`CLAUDE.md` §4.6 を更新
- **BGM・効果音・ボイスの規約も、商用利用の条件（クレジット表記など）を再確認する**

### 実施のタイミング

| 時点 | やること |
|---|---|
| いま | **何もしない。** 現行の茉白で開発を続ける |
| **残り5人の立ち絵に着手する直前** | **モデルを最終確認 → 茉白を試作 → 6人42枚を一気に作る** |
| 公開前 | §4 の表を更新し、クレジット文面（§6）を確定する |

**Civitai等のモデルには商用利用や生成物の扱いに条件が付くものがある。**
使ったモデル名とライセンスを必ずここに記録すること。seed は表情差分を作り直すときに要る。
