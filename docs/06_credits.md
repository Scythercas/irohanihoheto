## 1. 背景

### みんちりえ

- 配布元: <https://min-chi.material.jp/>
- 形式: JPEG 1920×1080
- **利用条件（2026-08-14 時点で各素材ページに記載の内容を確認）**

| 項目 | 可否 |
|---|---|
| 商用利用 | **OK** |
| 加工して作品に利用 | **OK** |
| クレジット表記 | **不要**（ただし表記が推奨されている） |
| **素材としての再配布・販売** | **禁止**（加工の有無を問わない） |

- **推奨クレジット表記**: `みんちりえ（ https://min-chi.material.jp/ ）`
  → **本作では表記する方針**（無料で使わせてもらっている以上、書くのが筋）

#### 【重要】再配布禁止への対応

**素材ファイルは公開リポジトリに含めていない。**
`.gitignore` で `public/assets/bg/` を除外し、取得は各自 `npm run fetch:assets` で行う運用にしている。

- 理由: 本リポジトリは**パブリック**であり、素材をそのまま置くと
  「素材としての再配布」に当たると判断されうるため
- ビルド成果物（GitHub Pages / itch.io に置く `dist/`）には当然含まれるが、
  それは**作品への利用**であり規約上問題ない
