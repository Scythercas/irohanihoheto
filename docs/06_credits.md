#### 【重要】再配布禁止への対応

**素材ファイルは公開リポジトリに含めていない。**
`.gitignore` で `public/assets/bg/` を除外し、取得は各自 `npm run fetch:assets` で行う運用にしている。

- 理由: 本リポジトリは**パブリック**であり、素材をそのまま置くと
  「素材としての再配布」に当たると判断されうるため
- ビルド成果物（GitHub Pages / itch.io に置く `dist/`）には当然含まれるが、
  それは**作品への利用**であり規約上問題ない

### ゲームまてりあるず

- 配布元: <https://game-materials.com/>
- **利用条件（2026-08-14 時点で利用規約ページを確認）**

| 項目 | 可否 |
|---|---|
| 商用利用 | **OK**（個人・法人問わず無料） |
| 加工・合成・変形 | **OK** |
| クレジット表記 | **任意**（一部用途では表記を要望） |
| **素材としての再配布・販売** | **禁止**（加工後の素材のみの販売も不可） |
| その他禁止 | 反社会的な利用、第三者に実害を及ぼす利用 |

※ 素材はMidjourneyで生成されたものと明記されている。
